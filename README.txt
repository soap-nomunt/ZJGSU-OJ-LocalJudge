ZJGSU Online Judeg System For Local v1.0
======================

这是一个不需要安装 Python、也不需要安装 gcc 的 Windows 便携版 C 语言判题器。
解压后双击 CJudge.exe 即可使用，判题完全在本机运行，不需要联网。

一、功能
--------
1. 随机抽题：内置“第一次月考题库”和“ACM必做题库”。
2. 题面展示：月考 53 题带有离线题面、输入输出说明和样例。
3. 代码编辑：内置编辑器，按题自动保存代码。
4. 本地判题：用程序自带的 gcc 编译，逐组测试，给出通过/答案错误/超时/运行错误/编译错误。
5. 差异提示：答案错误时显示输入、期望输出、实际输出和第一处不同。
6. 自定义输入：不判分，只运行程序查看输出。
7. 添加测试：在“测试结果”页点击“添加测试”，给当前题补充输入和期望输出。
8. 进度记录：记录每题尝试次数、最近结果和是否本地通过。

二、快速开始
------------
1. 把压缩包解压到一个本地文件夹。建议使用英文路径，例如 D:\CJudge。
   不要直接在压缩包里双击运行，也不要放在网络共享路径。
2. 双击 CJudge.exe。
3. 在左上角选择题库，点击“随机抽题”。
4. 在编辑器中写 C 代码，按 F5 或点击“测评”。
5. 在“测试结果”里查看每一组测试；失败时看下面的输入/期望/实际输出。

三、判定说明
------------
通过        本地全部测试通过。
样例通过    只有官方样例通过，还没有额外测试，不能说明代码完全正确。
答案错误    输出和期望不一致。
运行超时    程序运行超过题目时限。
运行错误    程序崩溃或返回了非零退出码。
输出超限    程序输出超过 8 MB。
编译错误    代码没有编译成功，查看“编译信息”。

重要：本地判题只代表本地测试通过，不等于学校 OJ 的 AC。
本地测试由官方样例和参考代码生成，无法覆盖 OJ 的全部隐藏测试。

四、题库和数据
--------------
- 月考题库：53 题，题面和样例来自学校 OJ（ZJGSU Online Judge）。
- 额外测试：用你在 OJ 上已经 AC 的代码生成期望输出，并做了交叉校验。
- ACM 题库：322 题，主要支持随机抽题；与月考重合的题目已有测试数据，
  其余题目暂无题面和测试数据。
- 题库 CSV 在 data\banks 目录，可以自己添加新的 CSV。

数据目录说明：
- data\statements      离线题面
- data\tests           样例和额外测试
- data\banks           题库 CSV
- data\catalog.json    题目元数据

五、用户数据保存在哪里
----------------------
默认保存在：
  %LOCALAPPDATA%\CJudge

其中包括：
  workspace\       按题保存的代码
  custom_tests\    你自己添加的测试
  progress.json    做题进度
  settings.json    设置
  logs\            运行日志

如果想做成 U 盘便携版，在 CJudge.exe 旁边新建一个空文件 portable.flag，
程序就会把用户数据保存到程序目录下的 userdata\ 中。
如果程序目录不可写（例如放在 Program Files），程序会自动使用 %LOCALAPPDATA%。

六、常见问题
------------
1. Windows 提示“Windows 已保护你的电脑”
   这是未签名程序的 SmartScreen 提示。点击“更多信息”，再点“仍要运行”。
   如果单位电脑禁止运行未签名程序，需要联系管理员。

2. 杀毒软件拦截 gcc 或编译出来的临时 exe
   本程序会调用自带的 gcc 编译代码，部分杀毒软件会误报。
   可以将整个 CJudge 文件夹加入信任区；不要关闭系统防护。

3. 编译器自检失败
   确认 toolchain\mingw32\bin\gcc.exe 存在，且压缩包完整解压。
   如果程序放在中文路径下仍然失败，尝试换到英文路径。

4. 程序一直超时
   检查代码里是否有 system("pause")、getch()、while(1) 等需要人工输入或死循环的语句。
   判题程序使用文件作为标准输入，不会有人工交互。

5. 程序无法读取文件
   OJ 题目只允许从标准输入读、向标准输出写。
   使用了 freopen 打开 in.txt 之类的代码在本地和 OJ 都会失败。
